# RATISS — Dictionnaire topologique

**Édition 0.1 · noyau initial · 25 octobre 2026**

Dictionnaire de notation mathématique pour décrire des structures topologiques et leurs relations entre domaines : quantique, géométrie/gravitation, thermodynamique, information, réseaux, IA, signaux et autres systèmes.

**Ce dépôt contient le langage et la traduction des formulations topologiques déjà présentes dans les travaux RATISS. Il n’ajoute pas de nouvelle loi physique.** Les prochaines hypothèses recevront leurs formules quand elles seront travaillées.

Contrôle d’inventaire : 97 dépôts publics recensés, 95 README récupérés, puis consultation ciblée des fichiers de code et de documentation des familles topologiques retenues. Cela ne constitue pas un audit ligne par ligne de chaque dépôt.

## Règles du dictionnaire

1. `K_D` désigne une structure topologique construite pour un domaine `D`; sa construction doit être écrite.
2. Un lien entre domaines est typé : analogie, représentation, interaction mesurée ou loi commune ne sont pas synonymes.
3. `P_sig` reste un **nom historique de dépôt**, pas un invariant universel. Le dictionnaire distingue sa définition opérationnelle selon chaque source.
4. Un graphe, une homologie, une aire de trajectoire, un verrouillage de phase et une signature logique sont des objets différents.
5. Une traduction formelle clarifie une hypothèse; elle ne prouve pas qu’elle est vraie.

## Couverture de cette édition

Le registre formalise notamment les formulations explicites de `RATISS-ODV-AEON`, `Travaux`, `RATISS-GRID`, `ratiss-focal`, `ratiss-continuums`, `RATISS-Bio`, `RATISS-NEURO`, `synchrotron-24`, `Crypto-net-veo-`, `ratiss-Skynet`, `ratiss-topological-decoherence-engine`, `ratiss-decoherence-atlas`, `RATISS-QPU-AMBIENT`, `QPU-Ratiss-COSMOS`, le banc Grover, `ratiss-lewm-integration`, `metac-bot-template`, `ratiss-vrn`, `RATISS-X`, `RATISS-ONE/Ratum`, Aeon Prime, Fusion-stark, `scientist-research-`, `RATISS-PHOTON` et `Ratiss-Jonathan-Labs`. Les éléments sans définition mathématique suffisante sont conservés comme **ouverts**, pas complétés par intuition.

Les notions adjacentes (Kuramoto/synchronisation, winding de phase, mesures de Bloch, invariants symplectiques, scores de risque ou de route et calculs Planck) sont identifiées et typées; elles ne sont pas renommées « homologie persistante » sans construction correspondante.
